# BodyParts

Компактный тренажёр по французским названиям частей тела.

## Live

- GitHub Pages: <https://polpal1623.github.io/BodyParts/>
- Репозиторий: <https://github.com/PolPal1623/BodyParts>

## Что внутри

- 26 терминов в словаре.
- 10 раундов в одной тренировке.
- Вопросы с выбором перевода на русский язык.
- Подсветка правильного и ошибочного ответа.
- Финальная история раундов и повторный запуск без перезагрузки страницы.

## Запуск

1. Откройте `index.html` в браузере.
2. Проект полностью офлайн и не требует сборки.

## Редактирование

- Данные лежат в массиве `DATA`.
- Длину тренировки задаёт `TOTAL_ROUNDS`.
- Интерфейс обновлён под общий стиль French Learning Suite.
