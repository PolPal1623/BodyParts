# Части тела — тренажёр французского языка

Небольшое одностраничное приложение, которое помогает выучить французские названия частей тела. Игроку показывается французское слово и фонетическая подсказка, а затем нужно выбрать правильный перевод на русский язык из нескольких вариантов. Игра рассчитана на короткие повторы, автоматически подсчитывает результат и показывает историю раундов.

## Возможности

- 🎯 **Тест на 10 раундов.** В каждом прохождении выбирается 10 случайных терминов из полной базы и перемешиваются варианты ответов.
- 🔁 **Немедленный перезапуск.** После завершения теста можно мгновенно начать заново, не перезагружая страницу.
- 🧠 **Фонетические подсказки.** Для каждого термина отображаются IPA-транскрипция и русская подсказка произношения.
- ✅ **Мгновенная обратная связь.** После выбора ответа кнопки подсвечиваются как правильные или неправильные, а ниже появляется текстовый комментарий.
- 📊 **Сводка прохождения.** Итоговый экран показывает количество правильных ответов и подробную историю всех раундов.
- 🌗 **Адаптация к теме устройства.** Интерфейс поддерживает светлую и тёмную темы через `prefers-color-scheme`.

## Технологии

Приложение написано на «чистом» HTML, CSS и JavaScript — без внешних зависимостей. Вся логика и база терминов находятся в файле [`index.html`](index.html).

## Как запустить

1. Склонируйте репозиторий или скачайте архив с исходниками.
2. Откройте файл `index.html` в современном браузере (Chrome, Firefox, Safari, Edge).
3. Нажмите кнопку «Начать» (игра стартует автоматически) и отвечайте на вопросы.

## Как адаптировать под свои нужды

- Измените массив `DATA` в конце `index.html`, чтобы добавить новые слова или заменить существующие.
- Подправьте значение `TOTAL_ROUNDS`, если требуется больше или меньше вопросов за сессию.
- Для изменения внешнего вида корректируйте CSS-переменные и стили, определённые в секции `<style>`.
